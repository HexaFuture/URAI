<h1 align="center">URAI</h1>

<p align="center">
  <strong>Make Code as Policy Great Again: Frontier Agents Write, Call, and Evolve Robot Tools</strong>
</p>

<p align="center">
  URAI (Universal Robot–Agent Interface) couples a programming agent that writes robot tools with an
  execution agent that calls them: each call runs a complete motion locally, and the agent decides what
  to do next from fresh observations.
</p>
